# ساخت و راه‌اندازی

## پیش‌نیازها

- فلاتر (کانال `stable`) و اندروید `SDK`
- PHP ۷٫۴ به بالا برای آزمون محلی سرور
- پایتون ۳ با `numpy` و `Pillow` (فقط اگر می‌خواهید صداها یا آیکون‌ها را دوباره بسازید)

## سرور

```bash
bash scripts/build-web.sh
```

این دستور اپ وب را داخل `plugin/iran-messenger/app` می‌سازد. بعد پوشه `plugin/iran-messenger` را زیپ و در وردپرس نصب کنید. بدون این مرحله افزونه کار می‌کند ولی اپ وب (برای آیفون) ندارد.

در پیشخوان وردپرس، منوی **IRAN Messenger**:

- **کد دعوت یک‌بارمصرف** بسازید؛ هر کس با کد ثبت‌نام کند فورا فعال است، بقیه منتظر تأیید می‌مانند.
- **سقف اعضا** و غیرفعال کردن عضو یا باطل کردن دستگاه هم همان‌جاست.
- **رله‌ها**: نشانی و کلید رله‌ها را وارد کنید تا برنامه‌ها وقتی نشانی اصلی مسدود است از آن‌ها استفاده کنند.
- بخش «دروازه پوش» در این نسخه استفاده نمی‌شود (اپ هیچ اتصالی به گوگل ندارد). خالی بگذارید.
- جستجوی گیف اختیاری است و کلید `GIPHY` خودتان را لازم دارد؛ در قطعی اینترنت بین‌الملل کار نمی‌کند.

### نکته‌های امنیتی سرور

- سرور را کسی بگرداند که اعضا به او اعتماد دارند؛ او می‌بیند چه کسی با چه کسی و کی پیام رد و بدل کرده (نه متن را).
- گزارش‌های دسترسی وب‌سرور (`access log`) آی‌پی اعضا را نگه می‌دارند. اگر می‌توانید کوتاه نگه دارید یا خاموش کنید.
- از پشتیبان‌گیری خودکار میزبان از پایگاه داده آگاه باشید.

## رله (اختیاری)

روی یک سایت وردپرس دیگر `plugin/iran-messenger-relay` را نصب کنید. در تنظیمات آن نشانی سرور اصلی و یک کلید تصادفی بلند بگذارید، و همان نشانی و کلید را در فهرست رله‌های سرور اصلی وارد کنید. رله باز نیست: فقط به همان یک سرور وصل می‌شود و فقط درخواست‌های امضاشده را رد می‌کند.

## اپ اندروید

### کلید امضا

هر ناشر کلید خودش را می‌سازد. کلید را هرگز در مخزن نگذارید (`.gitignore` آن را کنار می‌گذارد).

```bash
keytool -genkeypair -v -keystore app/android/release.jks -keyalg RSA -keysize 4096 -validity 10000 -alias release
```

بعد فایل `app/android/key.properties`:

```
storeFile=../release.jks
storePassword=...
keyAlias=release
keyPassword=...
```

نام و سازمانی که `keytool` می‌پرسد داخل گواهی ذخیره می‌شود و هر کس فایل اندروید را باز کند می‌بیند. اسم واقعی ننویسید.

### ساخت

```bash
cd app && flutter build apk --release --split-per-abi
```

برای ساخت نسخه‌ای که نشانی یک سرور مشخص در آن ثابت باشد:

```bash
cd app && flutter build apk --release --split-per-abi --dart-define=DEFAULT_SITE=https://example.org
```

فایل‌ها در `app/build/app/outputs/flutter-apk`. پیشنهاد: هش `SHA-256` فایل‌ها را کنار انتشار بگذارید.

اگر مخزن‌های استاندارد گوگل و `maven` از جایی که می‌سازید در دسترس نیست، نشانی آینه‌ها را (با ویرگول جدا) در متغیر محیطی `MAVEN_MIRRORS` بگذارید؛ لازم نیست فایلی را عوض کنید.

## آزمون

```bash
cd app && flutter analyze && flutter test
```

```bash
cd packages/irm_core && dart test
```

آزمون سراسری روی یک وردپرس محلی (هرگز روی سرور واقعی؛ حساب آزمایشی می‌سازد):

```bash
php scripts/local-dev-setup.php <wordpress-root> 3 --relay
```

```bash
cd packages/irm_core && dart run bin/e2e.dart http://localhost:8089 <code1> <code2> <code3> <path-to>/scripts/local-dev-setup.php <wordpress-root>
```

سرور محلی روی درگاه ۸۰۸۹ و رله روی ۸۰۹۰ (`php -S`).
