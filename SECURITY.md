# Security / گزارش آسیب‌پذیری

Please report vulnerabilities privately through this repository's **Security → Report a vulnerability** form, not in public issues. Include the version, steps to reproduce and the impact.

آسیب‌پذیری را در بخش عمومی (Issues) ننویسید. از فرم خصوصی **Security → Report a vulnerability** همین مخزن استفاده کنید و نسخه، مراحل تکرار و اثر آن را بنویسید.

Known limits are listed in [docs/threats-fa.md](docs/threats-fa.md).
